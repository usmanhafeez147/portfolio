# Usman Hafeez | Portfolio

Personal portfolio for Usman Hafeez, System Architect and Full-Stack Tech Lead.

Live site: https://usmanhafeez147.vercel.app

## Stack

- Next.js (App Router) with TypeScript
- Tailwind CSS
- Self-hosted Geist fonts
- Deployed on Vercel

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Edit the content

All text on the site lives in `src/data/profile.ts`: summary, skills, experience, projects and certifications. Update that file and the page re-renders.

## Build

```bash
npm run build
npm start
```
